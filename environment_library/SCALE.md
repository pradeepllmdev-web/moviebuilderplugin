# Real-world scale policy

`scale_policy.json` is the editable source of defaults: Unreal centimetres, lion/cat heights, doorway, residential/office floor heights, lane width, furniture profiles and reference assets for downloaded kits. `scale_policy.py` validates positive finite dimensions, converts metres once, computes building height from floor count, applies uniform scaling and calculates a ground/pivot offset from asset bounds. These are art-direction defaults, not universal standards or inferred floor counts.

`audit_asset_scale.py` reads only existing import metadata and writes `assets/scale-registry.json` for all 217 models. It chooses one reference asset per pack, derives one shared conversion, and applies that same factor to all assets in the pack. This preserves their relative sizes and proportions. Furniture reference is a chair with 90 cm overall height; its seat anchor cannot be inferred from total bounds. Suburban and industrial references use explicitly configured floor counts. Those assumptions should be reviewed against a reference image before production use.

`build_kit_demo_unreal.py` now uses that shared pack conversion instead of resizing every model to a separate arbitrary height. It also centers imported off-origin pivots horizontally and grounds their bounding-box minimum. Existing levels and assets are not rescaled retroactively. New runs create new versioned levels. A missing sofa-name selection was corrected to loungeSofa. The city builder now derives its facade floor spacing and height increments from the office-floor default; the physics builder reads character heights from the same policy. The house and natural-world builders retain their already authored centimetre dimensions; they do not automatically consume every policy field.

`build_scale_check_unreal.py` saves a separate real 3D comparison with both imported characters, 100 × 220 cm door opening, 2 m striped ruler, 75 cm table, a 90 cm overall chair, 9.9 m three-storey building and a native-scale scanned tree. The current tree is about 23.8 m tall. `capture_house.py --set scale-check` captures both character-height and wide views. The local studio shows them via scale_showcase.js.

Verified unit conversion, floor calculation, aspect preservation, off-centre pivot grounding and rejection of invalid/NaN/bool values with test_scale_policy.py. Scale comparison saved and screenshots inspected. This is a static scale reference, not validation of motion, foot contact, seated poses, window anchors or collisions. Semantic anchors and runtime foot IK remain separate tasks. Library-wide species/age tree validation and enforcement across 3dobjectnew's main production backend are not implemented by this local demo change.
