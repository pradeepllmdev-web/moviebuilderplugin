# dev_tools

Small helpers used while reviewing films (they were temporary scripts; kept so a new session has them).

* `play_scenes.py <scenes folder>`: watch a built film in the Blender viewer, scene after scene.
* `still_at.py` (Blender script): one still of a scene at a given second.
* `character_shot.py` (Blender script): a face or body shot of one character at a given second.
* Reviewing without opening Blender at all: `python review_pack.py films/<film>.py scenes/<folder>` (one HTML page, about 20 seconds).
