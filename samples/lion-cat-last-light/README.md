# The Last Light

A short original scene: Amber fears they have lost the forest path. Leo notices a lantern and reminds her that they only need enough light for the next step.

Uses the existing open-mouth lion and fresh Amber cat. No Meshy calls, downloads, or paid services. Four offline Windows voice lines, existing body performances, keyed mouth and blink controls, five camera cuts, procedural Blender forest, lantern lighting, and a quiet original synthesized score.

Run voice.py using the existing server Python, build.py using Blender, then finish.py using server Python. The editable scene is the-last-light.blend; output is the-last-light.mp4, with optional SRT subtitles.

This is a scene assembly prototype. Facial deformation and fur retain existing asset limitations. Body clips repeat; characters do not walk or hold the lantern. The environment is a stylized Blender set. Unreal and collision-free skinning are not validated.
