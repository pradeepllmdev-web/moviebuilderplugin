# The Riverbank Dash

Amber challenges Leo to race to the bridge. They sprint beside the river; Amber wins by a whisker, and Leo jokes that he will pick the shortcut next time.

Uses the existing lion and Amber cat, retained facial rigs, separately retargeted running motion, stride-based playback scaling, calm held poses outside the race, generated offline dialogue, five camera setups, a new procedural riverbank/bridge environment, and original locally synthesized music and ambience. No Meshy generation, credits or external paid calls.

Run voice.py using server Python, build.py using Blender, review start.png/race.png/finish.png, run render.py using Blender, then finish.py using server Python. Editable scene: riverbank-race.blend. Delivery: riverbank-race.mp4 and optional SRT captions.

This is a stylized prototype. Source facial rigs/fur remain imperfect; foot/toe contacts require visual review. Water is a shaded procedural surface, with no fluid interaction simulation. Footstep audio is a stylized rhythm rather than measured exact contacts. Original characters and earlier movies are preserved.
